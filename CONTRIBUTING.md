# Contributing

Workflow rules for this repository:

- **English everywhere**: code, comments, identifiers, documentation, commit
  messages and pull requests are written in English. In-game place names may keep
  Cyrillic where it serves the setting.
- **Pull-request workflow**: every change lands on `main` through a pull request
  opened from a short-lived feature branch (`feat/...`, `fix/...`, `docs/...`).
  No direct commits to `main`.
- **Commit style**: [Conventional Commits](https://www.conventionalcommits.org)
  (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`), concise imperative subject.
  No `Co-authored-by` trailers, no "generated by" footers — the commit subject
  and body speak for themselves.
- **Graphics decisions** follow [docs/graphics-plan.md](docs/graphics-plan.md);
  deviations are discussed in the pull request that introduces them.
